# Cartografia e SIG

Projetos e exercícios de cartografia e geoprocessamento, usando ArcGIS Pro e QGIS.

## Conteúdo
- Mapas temáticos e projetos de cartografia
- Análises espaciais (geoprocessamento, sobreposição de camadas, buffers)
- Modelos e workflows (ArcGIS ModelBuilder / QGIS Processing)
- Exportações de layouts de mapa (.pdf/.png)

## Estrutura
```
projetos/
  (arquivos de projeto .aprx / .qgz, exportações de mapas)
mapas/
  (imagens finais dos layouts)
```

## Progresso
- [ ] Primeiro mapa temático (QGIS)
- [ ] Análise de geoprocessamento (ArcGIS Pro)
- [ ] Workflow automatizado (ModelBuilder ou Processing Model)
- [ ] Integração com PostGIS (ver [`postgis-geo-queries`](../postgis-geo-queries))

> Nota: usar apenas dados abertos/públicos ou projetos próprios — não publicar dados de clientes ou dados sensíveis sem autorização.
